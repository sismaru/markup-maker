# Markup Maker (Excel to HTML Converter)

엑셀 데이터를 HTML 템플릿에 맞춰 자동으로 변환해주는 도구입니다. 기획전, 이벤트 페이지 등 반복적인 HTML 코딩 작업을 자동화할 수 있습니다.

## ✨ 주요 기능

- **3가지 템플릿 지원**: 기본(Default), 브랜드 리스트(Brand List), 상품 리스트(Product List) 템플릿을 선택하여 사용할 수 있습니다.
- **동적 상품 탭**: 기본 템플릿에서 상품 개수에 제한 없이 `+` 버튼으로 탭을 추가할 수 있습니다.
- **자동 이미지 경로 생성**: 브랜드 번호(`{U1}`)와 상품 번호(`{U2}`)를 기반으로 이미지 경로를 자동 생성합니다.
- **데이터 자동 정제**: 엑셀에서 복사할 때 생기는 따옴표(`"`), 빈 줄, 불필요한 공백을 자동으로 제거합니다.
- **스마트 붙여넣기**:
  - 엑셀에서 탭으로 구분된 여러 열 데이터를 복사하면, 첫 번째 칸에 붙여넣기만 하면 나머지 칸이 자동으로 채워집니다.
  - 탭이나 엔터로 구분되지 않은 단일 데이터는 해당 textarea에만 입력됩니다.
- **편집 가능한 라벨**: 각 입력 칸의 라벨명을 직접 수정하고 저장할 수 있습니다.
- **오름차순 번호 매기기**:
  - 브랜드 ID는 입력 순서대로 01, 02, 03... 부여
  - 상품 ID는 각 브랜드 내에서 입력된 순서대로 01, 02, 03... 부여 (중간에 빈 열이 있어도 순차적으로 매겨짐)
- **동적 주석 생성**: `<!-- 브랜드 01 -->`, `<!-- 브랜드 02 -->`와 같이 브랜드별로 구분 주석을 자동 생성합니다.

## 🚀 사용 방법 (Workflow)

### 1. 이미지 경로 패턴 설정
상단의 **이미지 경로 1 (브랜드)** 와 **이미지 경로 2 (상품)** 입력란에 규칙을 설정합니다.
- `{U1}`: 브랜드 순서 (01, 02, 03...)
- `{U2}`: 상품 순서 (01, 02, 03...)
- 예시: `../resource/20260119/pc_event_brd{U1}_prd{U2}.jpg`

### 2. 템플릿 선택
좌측 **HTML Template** 영역 상단에서 사용할 템플릿을 선택합니다.

| 템플릿 | 설명 | 입력 필드 |
| :--- | :--- | :--- |
| **기본 (Default)** | 브랜드 정보 + 상품 정보를 탭으로 관리 | 브랜드명, 브랜드랜딩, 최대할인율 / 온라인품번, 상품명, 할인율, 최종 가격 |
| **브랜드 리스트 (Brand List)** | 브랜드 정보만 입력 | 브랜드명, 브랜드랜딩, 최대할인율 |
| **상품 리스트 (Product List)** | 상품 정보만 입력 | 브랜드명, 온라인품번, 상품명, 할인율, 최종가격 |

- 선택한 템플릿에 따라 좌측 HTML과 우측 데이터 입력 폼이 자동으로 전환됩니다.
- 템플릿의 HTML 코드를 직접 수정할 수도 있습니다.

### 3. 엑셀 데이터 입력 (우측 패널)
엑셀 파일에서 데이터를 복사하여 붙여넣으면 **스마트 붙여넣기** 기능이 작동합니다.

#### 기본 (Default) 템플릿

1. **브랜드 정보 탭**:
   - 엑셀에서 **브랜드명 | 브랜드랜딩 | 최대할인율** 순서로 된 데이터를 복사합니다.
   - **브랜드명** 입력란에 붙여넣으면 나머지 정보가 자동으로 채워집니다.

2. **상품 탭**:
   - 엑셀에서 **온라인품번 | 상품명 | 할인율 | 최종가격** 순서로 된 데이터를 복사합니다. (4개 항목이 한 세트)
   - **온라인 품번** 입력란에 붙여넣으면 나머지 정보가 자동으로 채워집니다.
   - 상품이 더 필요하면 `+` 버튼을 눌러 탭을 추가하세요.

#### 브랜드 리스트 (Brand List) 템플릿
- 엑셀에서 **브랜드명 | 브랜드랜딩 | 최대할인율** 순서로 된 데이터를 복사합니다.
- **브랜드명** 입력란에 붙여넣으면 나머지 정보가 자동으로 채워집니다.

#### 상품 리스트 (Product List) 템플릿
- 엑셀에서 **브랜드명 | 온라인품번 | 상품명 | 할인율 | 최종가격** 순서로 된 데이터를 복사합니다.
- **브랜드명** 입력란에 붙여넣으면 나머지 정보가 자동으로 채워집니다.

> **참고**: 탭으로 구분되지 않은 단일 값을 붙여넣으면 해당 입력란에만 입력되고, 다른 입력란의 데이터는 유지됩니다.

### 4. 변환하기 (Convert)
상단의 **변환하기** 버튼을 클릭합니다.
- 변환된 결과 코드가 팝업으로 뜹니다.
- **결과 복사** 버튼을 눌러 클립보드에 복사한 후 사용하세요.

## 💡 팁 (Tips)
- **데이터 정제**: 엑셀 셀 안에 줄바꿈이 있거나 따옴표가 있어도 걱정하지 마세요. 프로그램이 알아서 깔끔하게 정리해줍니다.
- **라벨 커스터마이즈**: 각 입력 칸의 라벨명 옆 텍스트를 편집하고 **저장** 버튼을 누르면, 치환자 이름이 변경되어 다양한 데이터 구조에 대응할 수 있습니다.
- **탭 구분 없는 데이터**: 단일 값(예: URL 하나)을 붙여넣을 때는 해당 칸에만 입력되므로, 각 칸에 개별적으로 데이터를 넣을 수도 있습니다.
