# Markup Maker (Excel to HTML Converter)

엑셀 데이터를 HTML 템플릿에 맞춰 자동으로 변환해주는 도구입니다. 기획전, 이벤트 페이지 등 반복적인 HTML 코딩 작업을 자동화할 수 있습니다.

## ✨ 주요 기능

- **동적 상품 탭**: 상품 개수에 제한 없이 탭을 추가하여 데이터를 입력할 수 있습니다.
- **자동 이미지 경로 생성**: 브랜드 번호(`{U1}`)와 상품 번호(`{U2}`)를 기반으로 이미지 경로를 자동 생성합니다.
- **데이터 자동 정제**: 엑셀에서 복사할 때 생기는 따옴표(`"`), 빈 줄, 불필요한 공백을 자동으로 제거합니다.
- **오름차순 번호 매기기**:
  - 브랜드 ID는 입력 순서대로 01, 02, 03... 부여
  - 상품 ID는 각 브랜드 내에서 입력된 순서대로 01, 02, 03... 부여 (중간에 빈 열이 있어도 순차적으로 매겨짐)
- **동적 주석 생성**: `<!-- 브랜드 01 -->`, `<!-- 브랜드 02 -->`와 같이 브랜드별로 구분 주석을 자동 생성합니다.

## 🚀 사용 방법 (Workflow)

### 1. 이미지 경로 패턴 설정
상단의 **이미지 경로 1 (브랜드)** 와 **이미지 경로 2 (상품)** 입력란에 규칙을 설정합니다.
- `{U1}`: 브랜드 순서 (01, 02, 03...)
- `{U2}`: 상품 순서 (01, 02, 03...)
- 예시: `../resource/20260119/pc_event_brd{U1}_prd{U2}.jpg`

### 2. HTML 템플릿 입력
좌측 **HTML Template** 영역에 반복될 HTML 코드를 입력합니다.
- **치환자 사용**: 데이터가 들어갈 자리에 `{{브랜드명}}`, `{{상품명}}` 등의 치환자를 사용합니다.
- **브랜드 주석**: `<!-- 브랜드 01부터 오름차순 -->`이라고 적으면 결과물에서 `<!-- 브랜드 01 -->`, `<!-- 브랜드 02 -->`로 자동 변환됩니다.

### 3. 엑셀 데이터 입력 (우측 패널)
엑셀 파일에서 **열(Column)** 단위로 데이터를 복사하여 우측 입력란에 붙여넣습니다.
1. **브랜드 정보 탭**: 브랜드명, 랜딩 URL, 할인율 등을 입력합니다.
2. **상품 탭**: 상품별 품번, 상품명, 가격 등을 입력합니다.
   - 상품이 더 필요하면 `+` 버튼을 눌러 탭을 추가하세요.
   - 엑셀에서 복사할 때 따옴표가 포함되어도 자동으로 제거되니 그대로 붙여넣으세요.

### 4. 변환하기 (Convert)
상단의 **변환하기** 버튼을 클릭합니다.
- 변환된 결과 코드가 팝업으로 뜹니다.
- **결과 복사** 버튼을 눌러 클립보드에 복사한 후 사용하세요.

## 📝 사용 가능한 치환자 (Placeholders)

| 치환자 | 설명 |
| :--- | :--- |
| {{브랜드명}} | 브랜드 이름 |
| {{브랜드랜딩}} | 브랜드 랜딩 페이지 URL |
| {{최대할인율}} | 브랜드 최대 할인율 |
| {{상품명}} | 상품 이름 |
| {{온라인품번}} | 상품 코드 (품번) |
| {{할인율}} | 상품 할인율 |
| {{최종가격}} | 상품 최종 가격 |
| {{이미지경로1}} | 설정한 패턴 1로 생성된 경로 (주로 브랜드 이미지) |
| {{이미지경로2}} | 설정한 패턴 2로 생성된 경로 (주로 상품 이미지) |

## 💡 팁 (Tips)
- **데이터 정제**: 엑셀 셀 안에 줄바꿈이 있거나 따옴표가 있어도 걱정하지 마세요. 프로그램이 알아서 깔끔하게 정리해줍니다.
- **히스토리**: 작업 내용은 브라우저에 자동 저장되어, 새로고침 해도 설정이 유지됩니다.
