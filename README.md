# 🎬 Markup Maker (Excel to HTML Converter)

Markup Maker는 **엑셀 데이터를 내가 만든 HTML 템플릿에 맞게 자동으로 치환해 주는 스마트 웹 변환 도구**입니다.
쇼핑몰 기획전 페이지 제작, 상품 리스트 카드 마크업 등 반복적이고 지루한 HTML 복사-붙여넣기 작업을 1초 만에 자동화하여 마케터 및 퍼블리셔의 작업 효율을 극대화합니다.

---

## 🎨 주요 특징 (Key Features)

### 1. 사용자 정의 커스텀 템플릿 & 드래그 스크롤 🛠️
- 기본 제공 템플릿 외에도 사용자가 직접 에디터에 HTML 코드를 작성하여 영구 저장할 수 있습니다.
- 템플릿 생성 시 **필요한 데이터 열(Column) 개수를 1개부터 최대 20개까지 자유롭게 지정**할 수 있으며, 입력란이 동적으로 자동 렌더링됩니다.
- 템플릿 목록이 많아질 경우 마우스 드래그를 통해 편리하게 탐색할 수 있는 **드래그 스크롤(Drag-Scroll)** 기능이 적용되어 있습니다.

### 2. 스마트 붙여넣기 & 데이터 자동 정제 (Smart Paste) 📋
- 엑셀 표에서 여러 열의 데이터를 통째로 복사한 뒤, 첫 번째 데이터 입력창에 붙여넣으면 **탭(`\t`) 문자를 구분선으로 인식해 인접한 입력창들에 순서대로 자동 분배**됩니다.
- 문자열 복사 시 함께 딸려오는 불필요한 큰따옴표(`"`), 연속 공백, 앞뒤 빈 줄 등은 파싱 엔진이 알아서 깔끔하게 정제해 줍니다.

### 3. 실시간 데이터 저장 및 자동 복원 (Persistence) 💾
- **템플릿별 데이터 개별 캐싱**: 템플릿을 변경해가며 작업해도, 각 템플릿에 입력 중이던 데이터는 지워지지 않고 안전하게 개별 유지됩니다.
- **로컬 스토리지 연동**: 입력 데이터와 커스텀 템플릿 정보가 브라우저 저장소(`localStorage`)에 실시간 저장되므로, 새로고침을 하거나 실수로 브라우저를 종료해도 마지막 작업 상태가 그대로 복원됩니다.

### 4. 동적 상품 탭 및 템플릿 자동 동기화 🔄
- 기본 템플릿 사용 시, `+` 버튼과 `x` 버튼으로 **상품 탭을 자유롭게 추가 및 삭제**할 수 있습니다.
- 상품 탭을 추가하거나 삭제하면 좌측 에디터 내의 HTML 템플릿에도 해당 상품 블록(`<!-- 대표상품N --><li>...</li>`)이 **실시간으로 삽입/삭제 및 자동 번호 재정렬**되어 템플릿을 직접 수정할 필요가 없습니다.

### 5. 엑셀 격자 데이터 정리기 (Excel Grid Parser) 🪄
- 표 형태의 복잡한 엑셀 데이터를 왼쪽 아래 파서(Parser) 영역에 붙여넣으면 행 단위 데이터를 자동으로 깔끔한 카드 리스트로 정돈해 줍니다.
- **패턴 주기 모드**: 설정한 열 개수(기본 3열) 단위로 규칙적으로 데이터를 묶어 미리보기 카드를 형성합니다.
- **자동 입력 기능 (Auto-Fill) & 애니메이션**: 파싱된 카드 하단의 입력 대상 버튼(예: `data_1`, `품번` 등)을 누르면 해당 데이터가 우측 입력 필드에 자동으로 채워집니다. 입력 시 입력란이 깜빡이는 **플래시 효과(Flash Effect)**가 나타나며, 데이터 성격에 따라 자동으로 관련 탭(브랜드/상품)으로 화면이 전환되어 매우 편리합니다.

### 6. 편집 가능한 플레이스홀더 라벨 (Editable Labels) 🏷️
- 입력창의 기본 이름표(예: `data_1`, `data_4`)를 사용자가 원하는 직관적인 명칭(예: `브랜드명`, `할인가`)으로 수정할 수 있습니다.
- 라벨 저장 시 템플릿 내부의 치환자 코드(`{{data_1}}` ➡️ `{{브랜드명}}`)도 실시간으로 감지되어 일치하도록 자동 변환됩니다.

## 🚀 사용 방법 (Workflow)

### [1단계] 이미지 경로 패턴 규칙 설정 (상단 패널)
디자인에 들어갈 이미지 주소를 매번 하나씩 복사해 넣을 필요 없이, 규칙만 적으면 자동으로 이미지 경로를 동적 매칭해 줍니다.
- `{U1}` (또는 `{b}`, `{U}`): 브랜드 순서 번호 (01, 02, 03... 형식의 2자리 패딩 적용)
- `{U2}` (또는 `{p}`): 상품 순서 번호 (01, 02, 03... 형식의 2자리 패딩 적용)
- **예시**: `/resource/images/brand{U1}/prd_{U2}.jpg` 입력 시, 첫 번째 브랜드의 첫 번째 상품 이미지는 자동으로 `/resource/images/brand01/prd_01.jpg`로 치환됩니다.

### [2단계] HTML 템플릿 준비 (좌측 패널)
1. **기본 템플릿**: 브랜드와 상품 정보가 계층 구조로 들어가는 기본 템플릿을 제공합니다.
2. **커스텀 템플릿**: 
   - `HTML Template` 헤더 우측의 `+` 버튼을 클릭합니다.
   - 새 템플릿의 이름과 필요한 데이터 열 개수(1~20개)를 설정해 생성합니다.
   - 에디터 창에 뼈대가 될 HTML 마크업 코드를 짜 넣은 후 아래 **저장하기** 버튼을 누릅니다.

### [3단계] 엑셀 데이터 채우기 (우측 패널)
- 엑셀 표를 복사해 첫 번째 입력란에 붙여넣거나, 좌측 하단의 **행 Data 정리 (Excel Grid Parser)** 창을 이용해 가공된 데이터를 타겟 필드에 자동 입력합니다.

### [4단계] 변환 및 결과 복사
- 우측 상단의 **변환하기 (Convert)** 버튼을 클릭하면 최종 치환된 HTML 코드가 포함된 모달 창이 나타납니다.
- **결과 복사** 버튼으로 텍스트를 클립보드에 복사한 다음, 소스코드 파일이나 웹 에디터에 붙여넣어 완성을 진행합니다.

- [`js/parser.js`](file:///d:/mytest/markup-maker/js/parser.js): 엑셀 텍스트를 줄/열 단위 배열 및 TSV 형태로 다듬고 쪼개주는 파싱 가공 엔진

- [`js/app.js`](file:///d:/mytest/markup-maker/js/app.js): 이벤트 리스너 연동, 스마트 붙여넣기 배분, 드래그 스크롤, 탭 전환 등 데이터 흐름 전반을 조정하는 메인 사령탑 코드
